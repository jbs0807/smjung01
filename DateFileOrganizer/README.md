# 날짜별 파일 자동정리 1.3

Android 8 이상. 갤럭시 노트9 Android 10을 지원하도록 minSdk 26으로 빌드합니다.

1. 원본 폴더와 대상 폴더를 선택합니다. 휴대폰 저장소/SD카드만 허용합니다.
2. 사진·동영상·문서 중 처리할 종류를 고릅니다.
3. 접근 확인 후 검색합니다. 사진의 내용 분석은 APK에 포함한 ML Kit 모델이 기기에서 수행합니다. 인터넷 권한은 제거합니다.
4. 미리보기에서 사진 항목을 누르면 특징을 수정할 수 있습니다. 같은 날짜·특징의 사진에 일괄 적용할 수 있습니다.
5. 확인 후 이동을 누릅니다. 진행 중에는 화면을 유지하세요. 앱을 벗어나면 중지 요청합니다.

## 폴더와 날짜

- 사진: `261025-바다`, `261025-음식`, `261025-인물` 등. 불확실하면 `기타사진`.
- 문서: `261025-문서`. 문서 본문은 분석하지 않습니다.
- 영상: `261025-동영상`. 영상 내용 분류는 하지 않습니다.
- 날짜 우선순위: 사진 EXIF 촬영일/영상 기록일 → 파일명에 포함된 8자리 날짜 → 수정일 → 날짜미상.
- `261025`는 2026년 10월 25일입니다. 영상 기록일은 메타데이터에 기록된 날짜를 사용하므로 UTC 기록 영상은 현지 촬영일과 하루 차이가 날 수 있습니다.
- 선택한 원본 하위 폴더까지 검색합니다. 대상 폴더, 숨김 폴더, Android 폴더는 제외합니다. 시스템이 접근을 허용한 범위만 처리합니다.

## 데이터 보호

- 검색 전 파일명·메타데이터·사진 내용 접근을 명시적으로 확인합니다.
- 이동 전 확인창을 표시합니다. SHA-256으로 복사본 및 현재 원본을 확인한 후에만 원본 삭제를 시도합니다.
- 이름 충돌은 `_1`, `_2`를 붙여 보존합니다. 파일명은 날짜 폴더 안에서도 유지합니다.
- 저장 공간 부족/검증 실패/중지 시 원본은 보존합니다. 이미 검증한 대상은 원본 삭제에 실패하더라도 보존합니다.
- 갑작스러운 강제종료 때 대상에 미완성 복사본 또는 검증된 복사본이 남을 수 있습니다. 다음 실행에서 중단 상태를 알리며, 원본/대상을 확인한 후 다시 검색합니다. 자동 재개/되돌리기는 제공하지 않습니다.
- 파일 이동 이력은 앱 전용 저장소에만 기록하며 앱 백업은 비활성화합니다.
- 바다·인물 등은 자동 추정이므로 정확성을 보장하지 않습니다. 사람의 신원을 식별하지 않습니다.

## 빌드와 검증

JDK 17, Gradle 8.7, Android SDK 35. `gradle --project-dir DateFileOrganizer testDebugUnitTest assembleDebug`.
GitHub Actions에서 날짜 처리/충돌/복사 검증/중지/쓰기 실패 테스트와 서명·정렬·인터넷 권한 부재를 확인합니다.
실제 기기의 설치·분류 품질·SD카드 동작은 별도 확인이 필요합니다.
기존 앱과 서명 키가 다르면 덮어쓰기 설치가 거부될 수 있습니다. 기기 보호 기능을 자동 해제하지 않습니다.

## 변경 내역

기존 날짜 정리 앱의 폴더 선택 및 복사 후 검증 구조를 유지하면서 파일명 추측을 실제 이미지 분류로 변경했습니다. 미리보기 페이지, 특징 수정, 날짜 판별 보완, 진행 상태, 동시 작업 차단, 대상 폴더 재검색 방지, 중단 상태 기록을 추가했습니다.
