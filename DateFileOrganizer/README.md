# 파일 정리 1.6

Android 8 이상. 기존 com.example.dateorganizer.pro 앱과 같은 식별자와 서명키 경로를 사용합니다.

1. 원본 폴더를 누르고 연결된 위치에서 선택합니다. 새 위치는 ‘다른 위치 연결’에서 Android의 최초 허용 확인을 거칩니다.
2. 저장 폴더를 선택하거나 ‘원본 폴더 안에 정리’를 누릅니다. 다음 실행부터 선택과 권한을 복원합니다.
3. 사진·동영상·문서를 고르고 ‘파일 검색’을 누릅니다. 개인정보 접근 안내를 확인한 뒤 검색합니다.
4. 미리보기에서 파일을 눌러 같은 날짜의 폴더명을 한꺼번에 수정할 수 있습니다.
5. ‘파일 이동 실행’에서 대상을 확인합니다. 진행률·처리 개수·경과 시간을 확인하고 필요하면 중지합니다.

## 날짜와 폴더

촬영 메타데이터 → 파일명 날짜 → 수정일 순으로 날짜를 정합니다. 같은 날짜의 파일은 날짜-시·동 폴더 하나에 모읍니다. 파일명·URI 순서로 정렬한 해당 날짜의 첫 사진에 저장된 GPS를 사용하며, 위치를 확인하지 못하면 위치미상입니다. 위치명 조회는 Android Geocoder를 사용하며 실제 좌표 전달과 연결 여부는 제공자 구현에 따릅니다. 검색 전에 이 사실을 안내합니다. 이 버전은 위치 추출·파일 이동 알고리즘을 재작성하지 않습니다.

## 권한과 보호

최초 연결한 로컬 폴더의 읽기·쓰기 권한만 저장합니다. 자체 선택창은 그 범위의 하위 폴더만 읽고, 권한이 사라지면 다시 연결해야 합니다. 시스템 최초 허용창은 자동 승인하지 않습니다. 연락처·계정 접근 권한과 광범위 저장소 권한을 추가하지 않습니다.

복사본과 원본의 SHA-256 일치를 확인한 다음 원본을 삭제합니다. 이름 충돌은 번호를 붙입니다. 작업 중 앱을 벗어나면 중지를 요청합니다. 자동 되돌리기는 제공하지 않습니다.

## 검증

JDK 17, Gradle 8.7, SDK 35. `gradle --project-dir DateFileOrganizer testDebugUnitTest assembleDebug`를 사용합니다. GitHub Actions에서 단위 테스트, APK 서명과 정렬을 확인합니다. 실제 기기 설치·SD 카드·권한 복원·화면 배치는 기기 확인이 필요합니다.
