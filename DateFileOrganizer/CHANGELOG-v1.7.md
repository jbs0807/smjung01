# 파일 정리 v1.7

- 저장 구조를 `2026년/10월/261026-부산광역시해운대구`와 같은 년 → 월 → 년월일-시군구 3단계로 변경했습니다. 1~9월은 앞에 0을 붙이지 않습니다.
- 같은 날짜의 사진·영상·문서를 같은 폴더에 모읍니다. 최초 생성 시 파일명 순 첫 사진의 GPS를 기준으로 시·군·구를 사용하며 동·도로명·상세주소는 제외합니다.
- 이미 해당 월에 같은 날짜 폴더가 있으면 기존 폴더명을 재사용합니다. 미리보기와 진행 상태에도 전체 상대 경로를 표시합니다.
- 위치정보가 없거나 변환되지 않으면 `위치미상`, 날짜가 없으면 `연도미상/월미상/날짜미상-위치미상`으로 처리합니다.
- 내부 날짜는 4자리 연도를 유지하여 1900·2000·2100년대가 섞이지 않도록 했습니다.
- 새 구조에 정리된 모든 파일 종류는 재검색 시 건너뜁니다. 기존 한 단계 날짜 폴더의 파일은 새 구조로 정리할 수 있습니다.
- 기존 개인정보 접근 확인, 이동 전 확인, 복사 검증, 작업 중지, 이름 충돌 보호를 유지했습니다. 기존 앱 식별자와 서명 설정도 유지합니다.

실제 개인 사진이나 GPS를 사용하지 않고 가상 날짜·행정구역 데이터와 기존 복사 검증 테스트로 확인합니다. 실기기 설치 및 저장소 동작은 별도 확인이 필요합니다.
