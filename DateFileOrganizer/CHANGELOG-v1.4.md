# v1.4 · 폴더 선택과 실행 현황 개선

- 원본 폴더와 저장 폴더가 같은 경우 허용. `원본 폴더 안에 정리` 바로가기 추가.
- 다른 폴더, 원본의 상위 폴더, 다른 저장장치도 선택 가능. 원본 아래에 별도로 선택한 저장 폴더는 검색에서 제외.
- 현재 파일이 분류된 저장 위치에 이미 있으면 이동 대상에서 제외. 실행 시에도 재검사.
- 파일 목록 수집 후 날짜·특징 분류를 수행하여 분류 진행률을 실제 개수 기준으로 표시.
- 이동 진행률은 파일 개수와 현재 파일의 복사·검증 단계를 반영. 대용량 파일도 복사/검증 바이트가 실시간 갱신.
- 하단 진행 패널에 단계·진행률·처리 개수·경과 시간·현재 파일 표시. 실행·중지 버튼 고정.
- 네이비·화이트·청록 색상, 카드별 설정, 명확한 여백과 글자 크기, 활성/비활성 버튼 구분.
- 기존 SHA-256 검증 후 원본 삭제, 동일 이름 자동 번호, 중지 시 원본 보존, 접근 전 사용자 확인 유지.

## 사용 순서

1. 원본 폴더를 선택합니다.
2. `원본 폴더 안에 정리`를 누르거나 별도의 저장 폴더를 선택합니다.
3. 파일 종류를 선택하고 `검색 · 분류 미리보기`를 누릅니다. 접근 안내를 확인합니다.
4. 분류 결과를 검토합니다. 사진 항목을 누르면 특징 이름을 수정할 수 있습니다.
5. `파일 이동 실행`을 누릅니다. 실행 중 하단에서 상태를 확인하고 필요하면 중지합니다.

파일 찾기 단계는 전체 개수가 확정되지 않아 발견 개수를 표시합니다. 분류와 이동 단계의 진행률은 각각 0~100%입니다. 오류가 있어도 전체 시도가 끝나면 100%가 될 수 있으므로 결과의 이동·오류 개수를 확인합니다. 정리 중 앱을 벗어나면 원본 보존을 위해 작업을 중지합니다.
