# 파일 정리 v1.6

- 메인, 정리 옵션, 파일 미리보기, 진행 상태와 대화상자의 색상·글자·간격을 통일했습니다.
- 카드 안쪽 여백을 16dp에서 12dp, 카드 사이를 12dp에서 8dp로 줄였습니다.
- 이미 연결한 폴더는 앱 내부의 48dp 최소 높이 목록으로 탐색합니다. 긴 이름은 최대 두 줄로 표시합니다.
- 목록 검색, 상위 폴더, 현재 폴더 사용, 다른 위치 연결을 추가했습니다. 폴더 목록은 백그라운드에서 읽습니다.
- 읽기·쓰기 권한을 유지하고 원본/저장 폴더를 기억합니다. 권한이 사라지면 다시 연결해야 합니다.
- 새 위치 최초 연결 시 Android 시스템의 허용 확인은 필요합니다. 시스템 선택창의 행 간격은 앱에서 바꾸지 않습니다.
- 같은 날짜의 저장 폴더명은 모든 파일에 함께 적용합니다. 사진뿐 아니라 문서·영상 미리보기에서도 수정할 수 있습니다.
- 실제 날짜·GPS 분류 방식에 맞게 접근 안내를 수정했습니다. 사진 GPS의 시·동 확인은 Android Geocoder 제공자를 사용하므로 좌표의 외부 전달 가능성을 안내합니다.
- 개인정보 접근 전 확인 및 이동 전 확인을 유지합니다. 새 광범위 저장소 권한이나 접근성 권한을 추가하지 않습니다.
- 기존 파일 복사·검증·중지 처리와 앱 식별자, 서명키 경로를 유지합니다.

빌드에서 기존 단위 테스트와 APK 서명·정렬을 확인합니다. 실제 휴대폰의 설치, SD 카드 선택과 화면 배치는 별도 기기 확인이 필요합니다.
