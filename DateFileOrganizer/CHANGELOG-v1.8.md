# 날짜별 파일 정리 v1.8

- 첨부 화면을 기본 구성으로 유지하고 검색 전 빈 미리보기 영역을 숨깁니다. 검색 결과가 있거나 검색이 완료되면 미리보기를 표시합니다.
- 원본 폴더 선택 시 저장 폴더도 같은 위치로 자동 설정합니다.
- 저장 폴더는 저장 폴더 행 또는 ‘폴더변경시 선택’ 버튼으로 별도 변경할 수 있습니다.
- 재실행 시 저장된 폴더를 복원하며 저장 폴더 권한이 없으면 유효한 원본 폴더로 기본 설정합니다.
- 첫 번째 ‘폴더변경시 선택’과 두 번째 ‘파일 검색’ 버튼은 cyan, 마지막 ‘파일 이동 실행’ 버튼은 핑크색입니다.
- 기존 년/월/날짜-시군구 폴더 구조, 파일 검증 후 이동, 접근 확인 및 중지 기능을 유지합니다.
- 실제 사용자 파일이나 사진 GPS에 접근하지 않았습니다.
